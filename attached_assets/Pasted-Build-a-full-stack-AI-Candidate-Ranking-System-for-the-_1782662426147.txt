Build a full-stack AI Candidate Ranking System for the Redrob Hackathon challenge. 
The system ranks job candidates for a Senior AI Engineer role using a 
multi-dimensional hybrid scoring engine — NOT keyword matching.

=== TECH STACK ===
- Backend: Python + Flask
- Frontend: React + Tailwind CSS (Vite)
- All computation: CPU-only, no external API calls during ranking
- Libraries: scikit-learn, rank_bm25, sentence-transformers (all-MiniLM-L6-v2), 
  numpy, pandas, python-dateutil

=== WHAT THE SYSTEM DOES ===

User uploads a candidates JSON or JSONL file (up to 500 candidates for demo).
The system scores every candidate across 5 dimensions and returns a ranked list 
with scores and reasoning. User can download the result as a CSV in the exact 
submission format: candidate_id, rank, score, reasoning.

=== SCORING ENGINE (backend) ===

Implement these 5 scorers in separate Python modules under src/scoring/:

1. semantic_scorer.py
   - Use sentence-transformers all-MiniLM-L6-v2 (CPU)
   - Build a text representation from candidate: headline + summary + 
     career descriptions + skill names
   - Embed the JD and all candidates
   - Score = cosine similarity(candidate_embedding, jd_embedding)
   - Weight: 0.30

2. experience_scorer.py
   - years_of_experience: ideal range is 5-9 years (score 1.0), 
     3-5 or 9-12 years (0.7), outside that (0.3)
   - company_type_score: check career_history companies against 
     CONSULTING_FIRMS list [TCS, Infosys, Wipro, Accenture, Cognizant, 
     Capgemini, HCL, Tech Mahindra] — if ALL companies are consulting, 
     score 0.2; if some product company experience exists, score 0.7; 
     if primarily product companies, score 1.0
   - production_ml_score: scan career_history descriptions for keywords 
     like [deployed, production, shipped, A/B test, inference, latency, 
     pipeline, serving] — count matches, normalize to 0-1
   - final = 0.4 * yoe_score + 0.35 * company_score + 0.25 * production_score
   - Weight: 0.25

3. skill_scorer.py
   - HARD_REQUIRED skills (embeddings, vector database, sentence-transformers, 
     FAISS, Pinecone, Weaviate, Qdrant, Milvus, OpenSearch, Elasticsearch, 
     retrieval, ranking, NDCG, MRR, evaluation framework, Python): 
     each match worth 0.15, capped at 1.0
   - NICE_TO_HAVE skills (LoRA, QLoRA, PEFT, fine-tuning, LLM, XGBoost, 
     learning-to-rank, NLP, open source, distributed systems): 
     each match worth 0.05, capped at 0.3
   - PENALTY skills when they dominate (Computer Vision, Speech Recognition, 
     Robotics, TTS, Image Classification as the ONLY domain): subtract 0.3
   - Also score skill_assessment_scores from redrob_signals for relevant skills
   - final = min(1.0, hard_score + nice_score - penalty)
   - Weight: 0.25

4. behavioral_scorer.py
   - Parse redrob_signals and compute:
     a. recency_score: days since last_active_date → 
        0-30 days=1.0, 31-60=0.8, 61-90=0.6, 91-180=0.3, 180+=0.0
     b. availability_score: open_to_work_flag(1.0 or 0.3) * 0.5 + 
        (1 - notice_period_days/180) * 0.5
     c. engagement_score: recruiter_response_rate * 0.4 + 
        interview_completion_rate * 0.3 + 
        min(github_activity_score, 100)/100 * 0.3 
        (treat github_activity_score=-1 as 0)
     d. reliability_score: verified_email(+0.1) + verified_phone(+0.1) + 
        linkedin_connected(+0.1) + profile_completeness_score/100 * 0.7
   - final = 0.3*recency + 0.25*availability + 0.25*engagement + 0.2*reliability
   - Weight: 0.20

5. disqualifier.py
   - Returns a multiplier (0.0 to 1.0) applied to the final score
   - KEYWORD_STUFFER: if current_title contains any of 
     [Marketing Manager, HR Manager, Content Writer, Graphic Designer, 
     Accountant, Sales Executive, Civil Engineer, Mechanical Engineer] 
     AND skill count of AI keywords > 5 → multiplier = 0.05
   - CONSULTING_ONLY: if every company in career_history is in CONSULTING_FIRMS 
     → multiplier = 0.5
   - RESEARCH_ONLY: if career descriptions contain [PhD, research lab, paper, 
     published, academic] but ZERO of [deployed, production, users, shipped] 
     → multiplier = 0.4
   - HONEYPOT: if years_of_experience > 40 OR if candidate claims 
     "expert"/"advanced" proficiency in more than 12 completely unrelated 
     skill domains OR if a career role duration_months > 600 → multiplier = 0.0
   - LOCATION_PENALTY: if country is not India AND willing_to_relocate is false 
     → multiplier *= 0.7
   - Apply the LOWEST multiplier that matches (most severe wins)

=== HYBRID RANKER (src/ranker/hybrid_ranker.py) ===

final_score = (
  0.30 * semantic_score +
  0.25 * experience_score +
  0.25 * skill_score +
  0.20 * behavioral_score
) * disqualifier_multiplier

Sort by final_score descending. Assign rank 1 to 100 (or N if fewer candidates).
For equal scores, tie-break by candidate_id ascending.

=== REASONING GENERATOR (src/ranker/reasoning_generator.py) ===

For each ranked candidate, generate a 1-2 sentence specific reasoning string 
using ONLY facts from their profile. Format:
"[current_title] with [years_of_experience]yrs at [company_type] company; 
[top matching skill or career highlight]; [behavioral note like notice period 
or engagement]; [any concern if applicable]."

Never hallucinate. If a field is missing, skip it. Vary the structure per candidate.

- test_scorers.py: test each scorer returns float 0.0-1.0,
